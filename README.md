# cricket-score-tracker

A simple JavaScript cricket score tracker for two teams.

## Features

- Track runs, wickets, and overs for Team A and Team B
- Add runs (0, 1, 2, 3, 4, 6) ball-by-ball
- Record wickets (up to 10)
- Rename teams
- Reset each team score independently
- Live summary showing which team is leading

## How to run

Open `/home/runner/work/cricket-score-tracker/cricket-score-tracker/index.html` in a browser.
